# 向设备发送完整任务库

> **已被 [0029](0029-send-only-todays-tasks-to-the-device.md) 取代（2026-08-04）**：设备任务库收窄为仅当天任务。本篇保留作历史记录，勿按本篇实现。

设备应接收全部未完成任务，不按任务日期、是否设置日期或屏幕一次能够显示的条数截断。屏幕可以每次只展示其中一部分，但传输和设备本地保存必须覆盖今日、未来、过期和无日期任务，让设备断开手机后仍能进入任意未完成任务。任务完成后立即形成移除记录；任务删除成功后形成删除记录。首次绑定或设备任务库丢失时才发送完整任务库，平时用变化记录更新；历史结果只进入总结数据。代价是 App、通信协议和固件都必须处理不定数量的数据，并明确大数据包失败后的恢复规则。
