# 设备任务库只包含当天任务

取代 [0001](0001-send-the-complete-task-library.md) 与 [0002](0002-separate-task-and-schedule-sync-ranges.md)（2026-08-04 客户拍板）。

设备任务库只发送设备本地当天的任务：截止日期在当天的任务，加上用户在 App 里手动设为今天的无日期任务（该选择当天有效，次日自动过期）。未来任务、过期任务和未被选入的无日期任务不再发送——任务与日程自此使用同一个「当天」日期范围。数量仍不设上限：当天有多少发多少，不许按屏幕条数截断。

手动设为今天与移出今天都属于普通内容变化，走三分钟稳定窗；完成与删除仍即时。跨自然日后 App 立即按新的一天重新计算任务库并发送（不进稳定窗，与当天内容包同一轮，`0x23` 先行）；昨天的任务以增量删除移出。设备在新版本到达前继续使用旧的已提交任务库，不自行清空或按日期过滤——日期筛选永远是 App 的职责。

配套实现决定：任务库源指纹与稳定窗 checkpoint 携带本地日，跨午夜后旧待发事务自动失配、App 重启后跨日的在途稳定窗不被静默丢弃而是立即整库重算；旧格式 checkpoint 不做解码兼容（按当前阶段策略允许一次性失效，升级首启由下一次编辑或跨日自愈）。wire 字节布局不变。
